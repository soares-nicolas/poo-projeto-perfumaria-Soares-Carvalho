## Sobre

Sistema em Java que simula a **Essência do Poti**, perfumaria artesanal de Teresina que produz perfumes, velas aromáticas e difusores, com encomendas personalizadas. O projeto aplica encapsulamento, herança, classes abstratas e interfaces.
